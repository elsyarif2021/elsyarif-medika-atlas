Pengenalan aplikasi

Elsyarif Medika Atlas adalah kamus dan direktori medis berbahasa Indonesia. Gunakan untuk mengenali istilah medis dan mencari informasi tentang penyakit, obat, dokter spesialis, serta rumah sakit. Kamus juga mencakup obat herbal dan pengobatan ala Nabi.

Cara memakai kamus

  1. Ketik nama atau kata kunci di kotak pencarian. Gunakan kategori atau huruf awal untuk mempersempit hasil.
  2. Tekan Sebelumnya atau Berikutnya untuk membalik halaman. Di HP, Anda juga dapat menggeser halaman ke samping.
  3. Tekan bintang pada entri untuk menyimpannya ke Favorit.
  4. Jika istilah belum tersedia, tekan Tambah ke kamus, tulis penjelasan, lalu simpan. Anda juga bisa memilih Tambah artikel ke kamus pada hasil artikel yang sesuai.

Favorit dan entri tambahan tersimpan di browser atau instalasi yang digunakan. Pencarian artikel Wikipedia memerlukan internet.

Instal di perangkat

Buka situs ini di browser. Gunakan tombol Instal aplikasi jika browser menampilkan dialog pemasangan, atau ikuti petunjuk perangkat berikut.

Windows
Di Chrome, pilih ikon instal di bilah alamat atau cari opsi instal di menu. Di Edge, buka menu ⋯ → Aplikasi → Instal situs ini sebagai aplikasi.
macOS
Di Safari pada macOS Sonoma 14 atau lebih baru, pilih File → Tambahkan ke Dock. Di Chrome, gunakan ikon instal atau opsi instal di menu.
iPhone dan iPad
Di Safari, pilih Bagikan → Tambahkan ke Layar Utama. Aktifkan Buka sebagai App Web jika tersedia, lalu pilih Tambah.
Android
Di Chrome, buka menu ⋮ → Tambahkan ke layar utama → Instal. Nama pilihan bisa berbeda menurut versi browser.

Setelah dipasang, buka Elsyarif Medika Atlas lewat ikon di perangkat.
